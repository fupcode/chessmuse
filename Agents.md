## Technology constraints
- Use Python 3.12 for backend, engine adapters, analysis, LLM, and TTS orchestration.
- Manage Python dependencies and environments with uv: pyproject.toml, .python-version, and uv.lock.
- Run Python code and tests with uv run; use uv add to declare dependencies. Avoid mixing Python package managers.
